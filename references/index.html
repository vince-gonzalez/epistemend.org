Epistemend  ·  Reference Check

Which of these references are real?

Paste a bibliography. Every entry is looked up in the indexes that would hold it, and each one comes back with what was found and how well it matches what was written.

Everything runs in this page. The lookups go from your browser straight to Crossref, DataCite, OpenAlex, Europe PMC and OpenLibrary. Nothing reaches us, and there is nothing here to record it with.

What was consulted, and what it means

Crossref holds journal articles, books, chapters and conference papers. DataCite holds datasets, software and theses. Europe PMC holds the biomedical literature. OpenLibrary holds books and their editions. OpenAlex is asked about retraction.

A reference carrying an identifier is resolved directly. A reference without one is searched for, and the candidate that comes back is then compared against the words of the reference itself, because a search result is ranked by relevance and a relevant result can still be the wrong work.

Two sources need a server rather than a browser and run in the command line tool: PubMed, which declines requests from web pages, and the resolution of every outbound link to see whether it still loads.
