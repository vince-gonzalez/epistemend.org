Epistemend  ·  Order

The whole list, and every link in it.

Glance reads the first 25 references in your browser, free, against the same indexes this does. Three things it cannot do: the rest of the list, following each outbound link to see whether it still loads, and handing you a document with its own address that you can keep and forward. That is what this is.

What to check
Any citation style. The list is used for this check and is not kept after the report is delivered.
Payment is handled by Stripe. Card details never reach this site.

What arrives. An email confirming the order, then the report itself, usually within the hour. The report has its own address that you control and can send to anyone.

If it cannot be completed. A check that fails three times stops, tells us rather than you, and refunds automatically. Work that cannot be done is not work that gets billed.

What is kept. The findings, so the report stays reachable. The document you pasted is discarded once the report is written.
