Epistemend

Check a published record in one pass.

Paste an ORCID. You get one document: what the record says, where the work actually lives, and what disagrees between them.

Takes about a minute. Everything runs in this page — the requests go from your browser straight to ORCID, OpenAlex, Zenodo and Wikidata. Nothing reaches us, and there is nothing here to record it with.

—

Not covered here

  • Whether each deposited document agrees with its own record — needs the files, so it runs on the command line.
  • Whether outbound links still resolve — a browser cannot check other people's servers, so this runs on the command line too.
  • Anything requiring a repository to read.

Nothing above is scored or graded. Each section states what was found and what could not be reached; the reader draws the conclusion, because the same fact means different things for a first-year student and a professor of thirty years.

Checking a reference list instead

Paste a bibliography and every entry is resolved against the indexes that would hold it, with what was found set beside what was written. It needs no ORCID and no account.

The same checks, on the command line

pip install authorecon
authorecon-report 0000-0002-1825-0097

Nineteen checks, no dependencies. The command line version also reads deposited PDFs, resolves outbound links, and inspects dependency graphs — the things a browser is not allowed to do.
