Epistemend

Does every place your work lives still agree?

Publishing is the easy part. Keeping a record straight across ORCID, OpenAlex, Zenodo and Wikidata is the part nobody checks, and it goes wrong quietly.

A deposit gets a DOI and the DOI never reaches the index. A work is indexed under a name the author never claimed. A record cites something that no longer resolves. None of this announces itself, and all of it is checkable.

So check it. Paste an ORCID below.

Runs entirely in this page. The requests go from your browser to ORCID and OpenAlex directly — nothing is sent to us, and there is nothing here to log it with.

The same thing, on the command line

pip install authorecon
authorecon-discover 0000-0002-1825-0097 --out works.json

Standard library only, no dependencies. The page and the package do the same arithmetic, and the JSON this page offers is the file that command writes.

What it will not do

It reports what it could not reach rather than rounding it away. Every number reconciles out loud — works indexed equals works with a DOI plus works without one — because an unexplained gap between two numbers is indistinguishable from a bug.

A mistyped ORCID is refused against its check digit before a single request is made. One wrong character otherwise returns an empty result that reads as a career that never happened.
